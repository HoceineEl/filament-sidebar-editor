# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

Security fixes go to the latest minor release. Please upgrade to it before reporting.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately by email to **contact@hoceine.com**, or through GitHub's [private vulnerability reporting](https://github.com/HoceineEl/filament-sidebar-editor/security/advisories/new). Include the affected version, steps to reproduce and the impact you see.

You will get a reply within 3 working days. Confirmed issues are fixed and released as soon as possible, usually within 14 days, and credited in the changelog unless you prefer to stay anonymous.
